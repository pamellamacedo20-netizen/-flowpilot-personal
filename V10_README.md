# Pamella Academy V10

Clean-room member-area upgrade over the validated V9 base.

V10 adds persistent community, real global search, account/password flows, member avatar/banner uploads, catalog media upload, private course-file upload, functional catalog detail pages, support settings and exact Vimeo resume position.

Database migration: `supabase/migration_v9_to_v10.sql` inside the V10 overlay source.

This branch is isolated from FlowPilot `main` and must never be merged into that application.
