# Brand

Working name: **FlowPilot**. This is a working product name only; trademark and domain clearance are required before commercial launch.

## Positioning

Conversational automation for teams that want visual flows with clearer operational control: connection health, predictable usage and maintainable automation graphs.

## Visual system

- Primary: violet `#5B4BDB`
- Soft primary: `#ECE9FF`
- Background: `#F6F7FB`
- Surface: `#FFFFFF`
- Text: `#171A22`
- Muted: `#6F7685`
- Success: `#18815D`

The UI must not use the target app's logo, proprietary graphics, copied screenshots, trademarked wordmarks or copied product copy.
