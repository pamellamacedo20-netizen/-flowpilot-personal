# Component specs

## Button
Variants: primary, secondary, ghost, danger. Sizes: small/medium. States: default, hover, focus, disabled (production), loading (production).

## Flow node
Types: trigger, message, condition, action, delay, AI. States: default, selected, dragging. Contains header, title, body and in/out ports.

## Table
Used for automations and contacts. Search/filter states included.

## Inbox
Thread list, chat transcript, composer and contact metadata pane. Production version must support loading, retry, failed-send and attachment states.
